# Müşteri Sipariş Yönetimi

## Proje Hakkında
Bu proje, SQL Server kullanılarak müşteri ve sipariş verilerini yönetmek ve satış raporları oluşturmak amacıyla hazırlanmıştır.

## Kullanılan Teknolojiler
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

## Proje İçeriği
- Müşteriler ve siparişler tabloları
- Primary Key ve Foreign Key ilişkileri
- UNIQUE ve CHECK kısıtlamaları
- Örnek müşteri ve sipariş verileri
- Siparişler tablosu için indeks
- VIEW ile sipariş listeleme
- Stored Procedure ile müşteri harcama raporu
- Toplam, ortalama ve sipariş sayısı hesaplamaları

## Örnek Rapor
Stored Procedure, müşteri bazında sipariş sayısını ve toplam harcamayı hesaplar.

## Çalıştırma
1. `MusteriSiparisYonetimi.sql` dosyasını SQL Server Management Studio (SSMS) ile açın.
2. SQL Server bağlantınızı seçin.
3. Script'i çalıştırın.

## Amaç
Bu proje, SQL ve ilişkisel veritabanı yönetimi konularındaki temel becerileri göstermek için hazırlanmıştır.
